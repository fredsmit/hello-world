Upon its creation an iframe immediately has a document.
But that document is different from the one that loads into it!
So if we do something with the document immediately,
that will probably be lost.
How to detect the moment when the document is there?
The right document is definitely at place when iframe.onload triggers.
But it only triggers when the whole iframe with all resources is loaded.
We shouldn’t work with the document of a not-yet-loaded iframe,
because that’s the wrong document. If we set any event handlers on it,
they will be ignored.
